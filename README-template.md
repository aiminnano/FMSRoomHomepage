## Overview

### The challenge

Users should be able to:

- View the optimal layout for the site depending on their device's screen size
- See hover states for all interactive elements on the page
- Navigate the slider using either their mouse/trackpad or keyboard

## My process

I've started my project on mobile first then desktop and completing each section before proceeding to another one. I've noticed that my layout don't tend to break much this way because I fully understand how everything interacts with each other. Overall, I want to perfectly replicated the design and adding just a little bit of tweaks that I feel like improves the design.

### Built with

- Semantic HTML5 markup
- CSS custom properties
- Flexbox
- CSS Grid
- Mobile-first workflow
- [React](https://reactjs.org/) - JS library
- Tailwind CSS

### What I learned

Learned to use group hover, putting 'group' on the container and using 'group-hover' on each item inside that container.
